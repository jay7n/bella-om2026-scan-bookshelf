# 扫书 · AI 书架速览器

拍一张书架照片，AI 把书脊上的书名读出来，给每本书写一句话简介，做成可以左右滑的卡片。

给社区图书角用的小工具 —— 不用把书抽出来，就知道该借哪本。

## 为什么做这个

我经常去小区的图书角借书。每次站在书架前，书脊上的字又小又花，抽出来翻两页又塞回去，要挑好久。

后来我发现，难的不是书太少，是我根本不知道每本书讲什么。

大人可以掏手机查，但查出来的简介是写给大人看的，看不懂。

所以我做了「扫书」：**对着书架拍一张，它就把这排书讲给你听。**

## 怎么用

1. 点「拍下这排书」，对着书架拍一张（只拍一排，正对，光线足）
2. AI 一行一行读书脊，认出第一本，第一张卡就出来了
3. 左右滑着看，想借的点收藏
4. 滑完，收藏的书在「收藏」里，这一册书在「历史」里

## 每张卡上有什么

| | |
|---|---|
| 封面 | 豆瓣的书封，没有的用 AI 画一张 |
| 书名、作者 | 补齐书脊上看不清的字 |
| 推荐 | 👍 推荐 + 一句为什么 |
| 气质标签 | 轻松、好玩、有点好奇 |
| 钩子 | 一句让你想读的话，比如「你心里那团火，画出来是什么颜色？」 |
| 简介 | 35 字以内，说清讲什么 |

点「详情」还能看到豆瓣评分、简介、短评，以及四段解读：讲什么、为什么值得读、读之前要知道、最适合谁。

## 还有什么

- **可以填自己的信息**：几年级、性格、喜欢的类型。填了之后，每本书都会告诉你"适不适合你"，还能只看推荐的书
- **书架**：每拍一次存成一册，可以起名字，下次点开还能用闪卡再刷一遍
- **离线可用**：看过的封面和简介存在手机上，下次秒开

## 怎么运行

需要 Node.js 20.9 以上。

```bash
git clone https://github.com/jay7n/bella-om2026-scan-bookshelf.git
cd bella-om2026-scan-bookshelf

cp .env.example .env.local     # 然后填入 API Key
npm install
npm run dev
```

打开 http://localhost:3000

**必须填的**：`DEEPSEEK_API_KEY`（识别书名、写简介）
**可选**：`ARK_API_KEY`（AI 生成封面，不填就用程序画的封面）

手机上访问：电脑和手机连同一个 WiFi，打开 `http://<电脑主机名>.local:3000`。

部署说明见 [docs/DEPLOY-sealos.md](docs/DEPLOY-sealos.md)。
