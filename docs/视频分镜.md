# 扫书 · 2 分钟视频分镜（双层时间轴）

- 画幅 1920×1080 横屏，总长 2:10
- **底层：实拍，全程不断**（孩子在书架前，讲 + 操作）
- **上层：竖屏录屏画中画**（只在实际演示时出现）
- 音频最后统一配

## 一、版式

```
┌───────────────────────────────────────────────┐
│                                               │
│   实拍：孩子在书架前                            │
│                                    ┌────────┐ │
│                                    │ 竖屏    │ │
│                                    │ 录屏    │ │
│                                    │ 画中画  │ │
│                                    └────────┘ │
│              ─ 字幕 ─                          │
└───────────────────────────────────────────────┘
```

- 画中画：宽 420px，右侧留 80px，垂直居中偏上（top 180px）
- 字幕放底部居中，**不要压到画中画**
- 画中画加圆角 24px + 投影，看起来像贴在画面上的手机

## 三、实拍怎么拍（拍 8 条，每条约 10~20 秒）

孩子在书架前，**手机横屏固定在三脚架或支架上**，不要手持跟拍。

| 条 | 内容 | 参考时长 |
|---|---|---|
| A1 | 手划过书脊，皱眉 | 12s |
| A2 | 掏手机、开 App、举给镜头 | 10s |
| A3 | 对着书架拍，低头看屏幕，表情变化 | 18s |
| A4 | 看屏幕，手指滑动 | 20s |
| A5 | 对镜头讲，手指点屏幕 | 20s |
| A6 | 转身指书架上的书 | 12s |
| A7 | 对镜头讲（这段爸爸出镜） | 12s |
| A8 | 举手机，回头笑 | 12s |

**分开拍，不要一镜到底**：一条 20 秒，错了重拍也就 20 秒。10 岁的孩子撑不住 2 分钟连续表演。

## 四、两条文字卡（第 7、8 段浮层）

第 7 段，左侧浮出：

```
│ · 每张卡上说什么   │ · 查豆瓣书封和评分 │

│                  │ · 部署上线        │
└──────────────────┴──────────────────┘
```

第 8 段，右侧浮出：

```
视觉模型：读图上的书名
文本模型：写简介、判断推荐
开发中：AI 辅助写代码，判断由我们做
封面与评分：来自豆瓣图书
```

两张都用半透明深绿底 + 白字，压 30% 透明度，不要挡住孩子的脸。

## 五、录制顺序

1. **录屏**（C→D→E→F）：不用说话，每个动作做完停 1 秒
2. **实拍**（A1→A8）：固定机位，横屏，一条一条拍
3. **后期**：实拍铺满，画中画按时间轴贴上去，最后配音

## 六、录屏前必查

- 勿扰模式，关通知
- Safari 无痕窗口
- 提前扫一遍那排书，等封面文案全部加载完
- 填好个人画像
- 固定亮度，关自动锁屏
- 主演示用 20 本左右的一排书

## 七、后期要点

- 第 3 段识别动画可加速 1.5 倍，角落标「已加速」
- 画中画出现/消失用 0.3s 淡入淡出，不要硬切
- 实拍部分保持稳定，不要加转场特效
- 字幕白字 + 20% 黑底，避开画中画
