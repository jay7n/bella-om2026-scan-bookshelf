## 四、要拍的素材清单

| 编号 | 素材 | 时长 | 备注 |
|---|---|---|---|
| A | 书架前抽书又塞回去 | 10s | 竖屏或横屏都行，横屏最好 |
| B | 孩子举手机回头笑 | 8s | 横屏，留出右侧字幕位 |
| C | 完整扫描一次（拍照→识别完） | 40s | **录 3 条**，选最顺的 |
| D | 闪卡滑动 + 进详情 + 返回 | 30s | 特写钩子那一句 |
| E | 填画像 + 推荐筛选 | 25s | 要先清空画像重填，才有变化 |
| F | 书架页 + 播放闪卡 | 15s | |
| G | 文字板 3 张 | — | 第 7、8 段 + 片头标题 |

## 五、录制顺序

1. **先录屏**（C→D→E→F）：不用说话，专心操作，每个动作做完停 1 秒，方便后期卡点
2. **再实拍**（A→B）：找光线好的位置，横屏，孩子看镜头
3. **最后做文字板**：和第 7、8 段对上

## 六、录屏前的准备

- 勿扰模式，关掉所有通知
- Safari 无痕窗口，避开扩展
- 提前扫一遍那排书，等封面和文案全部加载完
- 填好个人画像（否则「仅显示推荐」不出现）
- 固定亮度，关自动锁屏
- 主演示用 20 本左右的一排书

## 七、后期

- 竖屏录屏放左侧，高度占 85%，右侧放实拍和字幕
- 第 3 段识别动画可加速 1.5 倍，角落标注「已加速」
- 字幕：白字 + 20% 黑底，字号别太小
- 配音最后录，对着画面念，一段一停
